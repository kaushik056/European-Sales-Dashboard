# European Sales Dashboard

Welcome to the European Sales Dashboard project! This Tableau dashboard provides a comprehensive analysis of sales data across Europe, helping users gain insights and make data-driven decisions.

# KPIs

The dashboard is designed to visualize critical metrics, including:

- **Number of Sales**
- **Profit**
- **Number of Customers**

## Features

The dashboard includes three main categories of analysis:

1. **Sales by Country**:
   - Visualizes sales performance across all European countries.
   - Provides a clear understanding of regional performance and trends.

2. **Sales by Product**:
   - Displays sales figures for each product, sorted from highest to lowest.
   - Enables users to identify top-performing products and areas for improvement.

3. **Monthly Sales Overview**:
   - Offers a detailed view of sales performance throughout the year.
   - Facilitates tracking of seasonal trends and monthly performance variations.

### Interactive Filters

To enhance user experience, the dashboard includes interactive filters that allow users to filter data by **specific months** , **specific country** , **specific product**.
These filters enable dynamic updates to the visualizations, allowing users to focus on the data that matters most to them.
